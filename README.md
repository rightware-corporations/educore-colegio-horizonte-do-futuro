# EduCore — Colégio Horizonte do Futuro

Repositório isolado do MVP comercial do **Colégio Horizonte do Futuro**, baseado no sistema EduCore.

## Regra operacional desta fase

- uma escola;
- um repositório;
- branch principal `main`;
- um deployment;
- um domínio.

O sistema interno EduCore é reutilizado. A personalização concentra-se na landing, identidade, assets, metadata/favicon e continuidade visual do login.

## Estado

A fundação foi sanitizada a partir da implementação funcional usada anteriormente no Colégio Páscoa. Branding, hostnames, media e páginas públicas específicas de escolas anteriores foram removidos.

A landing actualmente é **neutra e temporária**. Não deve ser apresentada ao cliente como design final antes da análise dos materiais reais do Colégio Horizonte do Futuro.

Ver `docs/HORIZONTE_MVP_HANDOFF.md`.
